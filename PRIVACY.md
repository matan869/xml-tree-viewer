# Privacy Policy — JSON & XML Viewer and Formatter

Effective: 2026-11-21 (first version 2026-08-28)

**This extension does not collect, transmit, store, or share any data.**

- All JSON and XML parsing and rendering happens locally in your browser.
- No network requests are made by the extension — it works fully offline.
- No analytics, no telemetry, no error reporting, no accounts.
- The `storage` permission is used only to remember two preferences inside your own
  browser profile: the theme (auto / light / dark) and whether JSON pages are
  formatted automatically.
- Page access is required solely to detect and render raw JSON and XML documents;
  the extension does not read or modify any other page.
